# a little world for bella ♡

A custom eight-chapter, interactive storybook built for Bella, by Andrew. Butter yellow, warm rose, handmade illustrations, tiny surprises, and meaningful words. **Completely different from `4bella`, `4kate`, and `4Marina`.**

## The eight chapters

1. **Invitation** (`index.html`) — giant interactive gift, custom illustration, animated stickers and secret surprise.
2. **The Map** (`world.html`) — whimsical illustrated world with six clickable destinations, no required reading order.
3. **The Bella Museum** (`museum.html`) — six custom-framed artworks with modal exhibit notes.
4. **The Greenhouse** (`garden.html`) — grow six flowers. Growth is saved in the browser, and can be reset.
5. **Stargazing Hill** (`sky.html`) — tap nine stars to reveal messages, complete the constellation, and make a shooting star.
6. **The Comfort Shop** (`pocket.html`) — a working stationery note dispenser with 24 different messages across four feelings and optional copy-to-clipboard.
7. **The Letter House** (`letter.html`) — an animated letter that opens from a handmade envelope.
8. **One Last Thing** (`ending.html`) — a final illustrated sunrise, heartfelt message, and flower keepsake.

## Running

Open `index.html` in any modern browser, or publish the entire folder as the root of a static site. Navigation uses relative URLs and works under any GitHub Pages project subpath. No Node, npm, build tools, API keys, or dependencies. Google Fonts are optional and have safe fallbacks. No third-party image hosting.

## Publishing on GitHub Pages

On a GitHub repository containing these files on `main`, go to **Settings → Pages**, select **Deploy from a branch → main → /(root)** and save. GitHub Pages for a project named `4bella-2` under `Sfg246` would normally be `https://sfg246.github.io/4bella-2/` after Pages is enabled. Confirm publishing succeeded before sharing.

## Personalization

All copy is in the HTML documents or the `site.js` message banks. If you want specific memories, inside jokes, favorite songs, or favorite flowers, replace the relevant generic copy before sharing. No claims about shared history were invented.

## Privacy / care

- No analytics, accounts, data collection, backend, tracking pixels or form submissions.
- Browser localStorage stores only which chapters were visited, grown flowers, and discovered stars. Nobody else receives this data.
- No autoplay audio. Gentle synthesized chimes require turning on the sound toggle.
- Motion reduction, native button semantics, keyboard navigation, dialog controls, focus indicators and phone-specific layouts are included.
- The letter admits wrongdoing without identifying the private incident, minimizing it, or pressuring the recipient into responding or forgiving. A website cannot substitute for changed behavior.
